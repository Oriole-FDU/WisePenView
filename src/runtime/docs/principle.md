# 聊天运行时分层

| 状态或职责                   | 归属                                                                  |
| ---------------------------- | --------------------------------------------------------------------- |
| 当前打开的会话               | React Router 的 URL。聊天页和侧栏按会话 ID 读取。                     |
| 输入、附件和工具选择         | 输入区 store。草稿获得会话 ID 时沿用本次输入。                        |
| 会话实例的建立、共享和回收   | `ChatRuntimeProvider` 持有的 `SessionCoordinator`。                   |
| 即时消息和 SDK 串流状态      | 每个会话各自持有的 AI SDK `Chat`。                                    |
| 历史加载、续流、取消和审批   | `SessionRuntime` 编排会话内操作。界面和运行时从同一规则推导展示状态。 |
| 已持久化的消息与实际回合状态 | 后端。Domain Service 提供请求入口，进入会话时由运行时对齐。           |

画面通过 `useChatSession(sessionId)` 读取消息、回合与历史。命令在调用时捕获会话 ID，
通过 `withSession` 保留该实例直到操作结束。切换会话只切换订阅，后台任务继续更新原会话。

运行时内部可以拆分消息合并和 SSE 转换函数。更新历史、推进回合和处理后端结果集中在对应的会话运行时。

具体的生命周期和回合规则见 [Chat 业务模型](./biz.md)。
